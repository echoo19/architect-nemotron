Architect is an agent factory. Type a job in one sentence and it builds an AI agent on NVIDIA Nemotron.

The agent only runs if it passed its exam. Change it, by hand or with a coding agent, and it stops with 0 model calls until it passes again or you undo.

Architect runs on Nebius Token Factory, as a desktop app and in the terminal. The main drawback is that the stop is a tripwire, not a lock. Watch the video or try it.

These are the sentences the app shows, with the numbers from my run of the demo agent in the example app, a receipt reader on Nemotron 3 Super whose model I changed by hand to the cheaper Lightning. Its exam uses development receipts, so these scores are not the published results further down.

How an agent gets its exam

Describe a job in plain words, like reading the totals off a receipt. Architect tries Nemotron models from the cheapest up. Each one practices on one set of cases, then takes an exam on cases it has never seen. The cheapest model that reaches the pass mark becomes your agent, and a model that does not pass is never installed.

Ten change requests, one run each

I wrote down ten ordinary change requests before any model call, such as "Make it faster." Each went once to Architect's own coder on Nemotron 3 Super, against the demo agent shown at the top of the page (Super, 59 of 100, pass mark 40).

  • 8

    changed the agent. All 8 stopped, and the app's next call made 0 model calls.

  • 3

    of those were retaken and passed, with 48, 46 and 48 of 100.

  • 5

    could not be examined: a model the settings do not have together with a changed budget, settings out of range, JSON that no longer parses, and an edit to generated code. They stayed stopped until Undo.

  • 2

    changed nothing, though the coder reported the work as done.

  • 0

    took a retake and missed the pass mark.

So the trial does not show the exam catching a change that made the agent worse, and it does not show any change improving it. I didn't measure whether the five edits that couldn't be examined would have broken the app.

By hand, outside the ten, I switched Super to the cheaper Lightning. It scored 29 of 100 on its retake, did not pass, and stayed stopped until Undo. This is one build, one agent and one coder model, on a demo exam of development receipts. The trial's table has every row.

What it does not do

The rule is a tripwire for a change nobody reviewed, not a lock. It stops calls made through the agent's own folder, so a coding agent can still edit the code that calls it, and someone who controls the computer and the signing key can get past it. Stopped means not examined, and passed does not mean better. A retake can examine a change to the task and rules text, the checks, the model and the settings. A change to anything else, such as the pass mark, the budget or the generated code, can only be undone. Architect won't retake an exam on a published set of cases, so the published receipt reader can only be undone. There's no plugin for Claude Code or Codex. The stop is file-based, and I've only recorded it with Claude Code and by hand.

Try it

Install the app, connect Nebius Token Factory with an API key, and describe the agent you want. The app needs nothing else installed and sets up Python the first time it opens.

{{downloads}}

Or run the terminal agent from a checkout, with git, uv and Node 20.6 or later. On the first run, choose Nebius Token Factory and paste the key.
