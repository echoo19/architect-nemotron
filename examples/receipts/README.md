# Receipt data (CORD v2)

Generated by `scripts/fetch_bench_data.py`; edit the script, never this file.

One text blob per receipt and four exact labels (`total`, `subtotal`, `tax`, `item_count`) for the receipt reader. Derived from CORD v2 under CC BY 4.0: see NOTICE.md. The rules, quoted word for word in every prompt, are in RULES.md and `task.json`.

| Set | Cases | Sources | Use |
|---|---|---|---|
| pilot | 150 | 150 train | measures the plain models and sets the bar; no build sees it |
| rehearsal | 100 (50 practice, 50 exam) | 100 train | development builds only |
| evidence | 200 (100 practice, 100 exam) | 200 train | the floor of the pre-registered builds |
| delivery | 348 | 166 train, 86 validation, 96 test | never seen by any build step |

Of CORD's 1,000 receipts, 140 were dropped as copies of another receipt, 24 because their copies disagree on a label, and 38 by hand because a label contradicts the text or the rules, or the text cannot be rebuilt in order. `manifests/excluded.json` lists each one with its reason, and RULES.md explains them.

- `cases/<set>.jsonl`: one case per line, `{"case_id", "task": {"receipt"}, "expected": {"total", "subtotal", "tax", "item_count"}}`, the format `forge run --cases` reads.
- `floors/<set>.json`: the rehearsal and evidence sets as Architect profile floors (a JSON array of the same cases). A profile names one with `"floors": {"cord-receipts": {"kind": "held_out_tasks", "path": "<path>/floors/evidence.json"}}`, the path relative to the profile file.
- `manifests/<set>.json`: the dataset revision, rule version, rules sha256 and file sha256s, then per case its source row, sha256s (ground truth, text, case) and flags. `manifests/source.json` pins the source files and every source row.
- `stats.json`: null rates, item counts, text lengths and flags per set.

Raw downloads are cached outside the repository (`C:/t/cord-cache` on Windows, `~/.cache/architect/cord-cache` elsewhere, or `CORD_CACHE`):

    uv run python scripts/fetch_bench_data.py                     # fetch and write
    uv run python scripts/fetch_bench_data.py --verify            # re-derive, compare hashes
    uv run python scripts/fetch_bench_data.py --verify --refetch  # from the source again
