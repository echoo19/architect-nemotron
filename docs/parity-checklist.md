## Not applicable to a local Python agent like Architect

- Cloud sessions, cloud environments and Codex Cloud: these need hosted infrastructure.
- Dispatch, Remote, mobile apps and device cards: these need phone apps and relay services.
- Chat, Cowork and Work tabs, Sites, dots, Space and Quick chat to ChatGPT: these are separate products.
- Enterprise MDM, admin console and managed settings: Architect has no organization.
- Claude Projects: this is cloud multi-thread orchestration.
- Computer use, Appshots, Computer History and Record & Replay: these need OS automation, and the local-GPU/OS-control scope is out.
- iOS Simulator pane: macOS and Xcode only.
- Pets and voice: novelty or extra models, not core.
- Shared snapshots: need hosting.
- Code Review PR inbox and auto cloud review: GitHub-hosted.
- Plan-limit cards and auto-continue: subscription specific. An API rate-limit retry is the analog.
- Fast/Ultrafast tiers: provider billing.
- Partner "Sign in with ChatGPT": vendor-specific.
- Chrome extension: an external product.
