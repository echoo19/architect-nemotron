## Sandbox module
SandboxError(ValueError).
validate_source(source:str,artifact:HarnessArtifact)->None.
sandbox_harness(artifact:HarnessArtifact)->Harness.
rebind_source(source:str,old:HarnessArtifact,new_spec:Spec)->str.

Structural capability sandbox PLUS isolated subprocess; NOT arbitrary unrestricted Python. Reject unsupported code before any execution. Support emitted preset wrapper imports/annotations (strip trusted exact imports, never execute authored imports), async run(context,task), JSON literals/local assignments, bounded simple conditionals/returns, await context.call, and await execute_preset with literal validated name/params/components/spec bound exactly to artifact. Allow only explicitly needed safe JSON operations, no arbitrary attribute traversal, reflection, decorators, imports, dynamic calls, comprehensions, unbounded loops, filesystem/network/process/environment access. Resource limits: source<=64KiB, AST<=2000 nodes, protocol messages<=128KiB, <=64 calls. Closed allowlist, not blacklist. Code+task go to worker process in empty temporary cwd and minimal environment (no credentials/home). Worker sees no expected labels, dataset handles, heldout cases, signing credentials or telemetry paths. Worker executes only validated restricted AST. Parent handles sequential model-call RPC through existing RunContext.call; quotes/wallet/deadlines remain trusted and all model usage is charged. No stdout passthrough. Cancellation/error always terminates and reaps child; whole runtime deadline applies. Explain actual boundary in docstring/tests: restricted language, not OS isolation of arbitrary Python. Rebinding replaces literal execute_preset spec argument after validating old source; direct guarded-call source may be reused unchanged, but new artifact/spec/report is always new. Test malicious attribute/import/class/function/default/decorator tricks, task/metadata injection, timeout/cancel, budget, no filesystem/network capabilities, normal wrapper and changed control flow.

## Stage3 module
RewriteProposal Pydantic frozen extra-forbid: diff:str (<=64KiB unified diff ONLY harness.py), components:tuple[str,...].
RewriteResult Pydantic: best:CandidateEvaluation, attempts:int, accepted:int, failures:tuple[str,...].

Exact primary floor definition; smoke is a separate fixed trusted tuning-only set with compatible floor definition. Never acquire heldout, even smoke. Use full floor.tuning and smoke_floor.tuning; require nonempty valid sets/minimum counts. Proposals are actual guarded model calls via Runtime.evaluate with Budget(tokens=32768,cost_usd=1,compute_s=30), max_output_tokens8192 (enclosing compile wallet still covers them). Task budget applies to candidate execution, not code-generation response length. Prompt gets current code/config and numeric tuning failures, no heldout or labels. Strict JSON proposal, bounded source/diff, exact single-file unified diff, no path escapes or creates/deletes/renames. Every candidate new atomic numeric version under artifact_root/spec_hash/version, no overwrite. Metadata components must be a valid preset subset retaining required components; validate code via sandbox; save execution_mode=sandbox and no report. Full tuning and fixed smoke must both pass floor+budget with no hard errors. Keep edit only if measured mean dollar cost strictly decreases versus previous candidate; for a zero-dollar baseline permit strict actual mean-token decrease with no cost increase. Measurement gains mean_tokens:float|None=None, populated from consumed usage in evaluate_cases; absent means token fallback unavailable. Never scan historical rows for this. Partial consumed baseline cost is a conservative LOWER bound, not invented full consumption. Zero observed cost cannot justify a positive-dollar rewrite. Reject all other edits. Accepted candidate becomes base for next iteration; stop on complete successful repair (one accepted repair is enough). Attempts hard-capped incl malformed/unsafe/rejected proposals. No signing/licensing. Emit one metadata-only telemetry row per proposal outcome (task_type categorical('rewrite'), accepted, actual floor score if measured, zero billing; actual proposal/model rows billed separately). Persist diff as rewrite.diff sidecar. No model free text in report/failures/telemetry. Fixed failure codes only.

## Integration and exit
Compiler selects library, tunes fresh spec, invokes Stage3 only if tuning fails and enabled+adapter+smoke present, then always Stage4 with current best tuning evidence. A successful rewrite replaces failed tuning evidence. On every final licensed artifact library.store; on warm Stage4 result library.record_verification(source, report passes). Warm custom code remains sandboxed and is rebound to new spec, evaluated on full tuning, then full heldout; no preset reset masquerading as reuse. Stage4 library failure cannot return cached report. Stage2 budget failure -> actual scripted diff removes component -> measured cheaper tuning+smoke -> full heldout license and accepted rewrite telemetry. Registry drift calls recompile but rejects worse report. Same spec twice warm-starts and counts Stage4 twice. All six phase exits eventually remain green.

LibraryLifecycle runtime-checkable Protocol has store(artifact)->str and record_verification(source,passed)->None; custom lookup-only Phase3 providers stay supported without hooks. Default Compiler now creates HarnessLibrary beside artifact_root; explicitly passed NullLibrary opts out.

Compiler failure results preserve fixed Stage3 rejection reasons and rewrite_cap when exhausted, in addition to the signed Stage4 gate failures. Successful repairs need not surface rejected exploratory attempts as final failure.

Native warm-source equivalence canonicalizes literal dictionary key order before AST comparison. Disk JSON metadata sorting must not reject an otherwise identical preset wrapper. All executable AST structure and literal values remain identical; no arbitrary native rewrite is accepted.

## Review correction: independent drift floor roles
TelemetryRow gains floor_role:Literal['primary','secondary']='primary' (closed, content-free, backward-compatible default). evaluate_cases(..., *, floor_role:Literal['primary','secondary']|None=None) infers the role from exact floor definition when omitted, validates explicit role against its declared definition, and labels aggregate scores; Stage4 explicitly uses secondary on its secondary measurement. Registry persists role per observation and maintains independent rolling windows against each configured floor definition, never mixing even when kind/limit match. Existing rows default primary; migrate existing SQLite observations with role default primary if needed. Changed model detection still applies to otherwise matching rows. Any configured floor breach/trend triggers recompile. Same UUID remains idempotent. Secondary scores cannot mask primary breach.

## Additional CLI review corrections (before implementation)
Registry.install gains keyword allow_budget_increase:bool=False. Automatic monitor never enables it. Without explicit trusted operator allowance, all candidate Spec budget ceilings must be <= incumbent ceilings (not merely observed usage). Candidate still needs a strictly better report and valid license. Explicit manual allowance does not bypass quality/authenticity. Current activation timestamp is persisted internally on install and rollback; observe ignores pre-activation telemetry so compile-time scores cannot seed field drift. Rollback begins a fresh observation window for the restored version. Migrate existing current rows conservatively with activation=now if missing. Telemetry remains append-only; reset only the registry's derived window. Timestamp comparisons use UTC-aware instants; invalid/naive timestamps may be refused/ignored. Tests need truly post-install timestamps for new field observations.
Sandbox parsing maps MemoryError from parser resource exhaustion into SandboxError; still fail closed, never broaden language.
