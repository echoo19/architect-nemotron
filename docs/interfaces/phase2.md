## architect.presets (one worker)
PresetError(ValueError), UnknownPresetError(PresetError).
ParameterRange(BaseModel frozen): values:tuple[JsonValue,...] nonempty distinct; default:JsonValue contained in values.
Preset(BaseModel frozen): name:str, components:tuple[str,...], tunable_params:dict[str,ParameterRange], removable_components:tuple[str,...]. validate_params(params:dict[str,JsonValue])->dict[str,JsonValue] merges defaults, rejects unknown/out-of-range keys. build(spec:Spec,params:dict[str,JsonValue]|None=None,components:tuple[str,...]|None=None)->Harness. emit(directory:Path,spec:Spec,params:dict[str,JsonValue]|None=None,components:tuple[str,...]|None=None)->None writes runnable async run(context,task) harness.py plus preset.json containing config. Components must be valid subset, nonremovable retained. Emit frozen config literals in code (NOT reading mutable unsiged config). Generated code delegates to execute_preset(name,params,components,spec_json,context,task). emit must produce equivalent behavior to build; code changes allowed later via safe Stage3.
get_preset(name:str)->Preset, all_presets()->tuple[Preset,...]. Exactly extractor,synthesizer,recommender,coder,explorer,planner,verifier in Phase2. hypothesis_tester later only.
async execute_preset(name:str,params:dict[str,JsonValue],components:tuple[str,...],spec_json:dict[str,JsonValue],context:RunContext,task:JsonValue)->JsonValue.
Tunables bounded small grid: context_window (e.g.512/2048), verifier_depth(0/1), retries(0/1), terseness(0/1), max_output_tokens(64/128). Model calls always context.call, sequential. No naked adapter invocation. Components actually change behavior/calls; do not merely list cosmetic names. Effective verifier_depth=0 disables optional verification even when available. Avoid huge full grids by at most 3 tunables per preset (choose those meaningful).
extractor strict output JSON schema, self-check; synthesizer prose output; recommender retrieval + preference memory from task inputs (no private external service), returns recommendation; explorer probe/interface analysis from task; planner bounded plans (object schemas use steps); verifier verdict (object schemas use passed/reason). Explicit string output schemas may return prose plans/verdicts; the Spec output schema is authoritative. Tool inputs are explicit JSON, no eval/shell execution. Coder Phase2 is pack interface stub: emit additionally writes a pi-pack.json interface description with backend='pi_pending'; build/execute smoke still makes a guarded model call and returns the declared output schema (like other presets), never executes shell. This is NOT a coding backend yet. Phase5 replaces backend.
Output validation: JSON Schema via jsonschema dependency (integrator adds). If schema.type='string', preserve raw model text; object/array/number/bool/null require JSON parsing + jsonschema validation. Never silently accept invalid output. Retry can repair within budget. Optional self-check/verifier calls must validate returned output or verdict, not free extra call ignored. Return final task output (not internal trace). Fixtures will supply proper responses. Runtime evaluate records behavior. Pipeline execution of full Spec.pipeline can be deferred Phase3, but do not silently claim it exists.
Ownership: architect/presets/** + tests/test_presets.py only. Golden/failure each preset, actual calls/component change, emission roundtrip, schema rejection.

## architect.floors (one worker, may use separate files per evaluator)
FloorError(ValueError), HeldOutAccessError(PermissionError), CalibrationError(FloorError).
EvaluationCase(BaseModel frozen extra forbid): case_id:str, task:JsonValue, expected:JsonValue, metadata:dict[str,JsonValue]={}.
EditLogRow(BaseModel frozen): case_id:str, task:JsonValue, proposed:JsonValue, shipped:JsonValue, changed:bool. Validate changed == (proposed != shipped). JSONL format documented in docstring, example dataset test fixture integrator owns.
CalibrationRow(BaseModel frozen): case_id:str, task:JsonValue, output:JsonValue, human_score:float [0,1].
FloorEvaluator abstract common interface:
  definition:FloorDefinition
  tuning property -> tuple[EvaluationCase,...] (deep copies, never heldout)
  held_out property -> raises HeldOutAccessError always (no raw public accessor).
  _verification_cases(capability:object)->tuple[EvaluationCase,...] requires identity token from architect.floors._access, returns fresh deep copies. No bool/string/type-only credentials accepted.
  async score(cases:Sequence[EvaluationCase],outputs:Sequence[JsonValue])->float (finite[0,1]); exact lengths, nonempty, unique cases, membership in authorized partition, no output-less static score. A compiler must execute candidate on tuning task, never score historic proposed outputs only.
  passes(score:float)->bool (human edit <=limit, others >=limit).
At construction split deterministic by case_id stable hash with fixed seed or sorted even/odd; reject duplicates and overlapping caller IDs. Constructor accepts records then split internally, not caller-controlled tuning/heldout lists. Guarantee each partition nonempty, HumanEditRate each >=minimum_samples default30. Compiler cannot override split. No heldout tasks included in repr/model_dump/public vars. Private trusted Python boundary explicit; no promise against hostile reflection, Stage3 sandbox must not import package.
_access.py: private _VERIFIER_CAPABILITY identity object. Only future architect.compiler.verification may import this in production (independent static test scans imports). Public score rejects heldout without authorized case provenance from _verification_cases. This can use partition-scoped deep-copy tokens stored externally / case digest allowlist; keep design simple, explain exact capability boundary in module docs. DO NOT expose token in package __init__.py or tuning objects.
HeldOutTasks(definition:FloorDefinition,records:Sequence[EvaluationCase],checker:Callable[[JsonValue,JsonValue],bool]|None=None): defaults equality expected/output; fraction pass.
HumanEditRate(definition,records:Sequence[EditLogRow]): cases expected=shipped; score fraction candidate output != shipped, not original log changed bit. from_jsonl(definition,path:Path)->HumanEditRate.
LLMJudge(definition,records:Sequence[EvaluationCase],calibration:Sequence[CalibrationRow],judge_adapter:ModelAdapter, runtime:Runtime, judge_budget:Budget|None=None): refuse missing fixed nonempty rubric/model, mismatched adapter, missing calibration_dataset or empty calibration. Fixed adapter throughout. Calibrate before first scoring: judge fixed examples through Runtime.evaluate, scores parsed from JSON numeric [0,1]; refuse mean absolute human disagreement >0.15 (config constructor calibration_tolerance:float=0.15 allowed). Each score call evaluates candidate output, not supplied expected value. Use distinct synthetic judge Spec with correct model and budget, logs normal guarded evaluations. No raw judge outputs in telemetry. score average. Calibration + rubric/model immutable at evaluator boundary.
HeldOutGameScore(definition,records:Sequence[EvaluationCase],environment:GameScorer): GameScorer Protocol async score(task:JsonValue,output:JsonValue)->float. Score mean, reject nonfinite/out-of-range, environment only sees selected cases. Stub environment used in tests; actual ARC later. Don't invent new floor.
Ownership: architect/floors/** + tests/test_floors.py ONLY. All 4 floor modes, split invariants, output dependency, calibration failure, insufficient data, malformed logs, thresholds/boundaries.
