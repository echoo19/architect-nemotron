## 1. Claude Code Desktop (Code tab) - primary source https://code.claude.com/docs/en/desktop (read in full)
**Layout/nav**: Claude Desktop has three tabs: Chat, Cowork, Code. In Code, each conversation is a "session"; left sidebar lists sessions, "+ New session", filters by status/project/environment, group by project, "Projects" and "Customize" (connectors/skills/plugins) entries. Session title in toolbar (click to rename). Toolbar "Views" menu opens panes.
**Pane workspace**: chat, diff, browser, terminal, file, plan, tasks, subagent panes (+ iOS Simulator on mac). Drag pane header to reposition, drag edges to resize, pop a pane out to its own window and dock back; Cmd/Ctrl+\ closes the focused pane. Cmd/Ctrl-click a sidebar session opens a second session side by side (split).
**Parallel work**: Parallel sessions; in a git repo, a "worktree" option next to the branch name gives the session an isolated copy under `<project>/.claude/worktrees/` (location and branch prefix configurable); hover a session and click the archive icon to remove the worktree; optional auto-archive after PR merge/close; `.worktreeinclude` copies gitignored files such as .env. Claude can list, read and message other sessions. Side chat (Cmd+; or /btw) uses session context without polluting it; not persisted. Environments: Local, Cloud, SSH, WSL. Dispatch (phone) sessions get a "Dispatch" badge. OS notification when a background session finishes.
**Tool calls/diffs/approvals**: Transcript view modes: Normal (tool calls collapsed into summaries), Thinking, Verbose (every call); Ctrl+O cycles. A diff-stat chip like `+12 -1` appears; clicking opens the diff viewer (file list left, changes right). Click a line to comment, Enter adds, Cmd/Ctrl+Enter submits all comments at once; Claude responds with a new diff. "Review code" button has Claude leave review comments in the diff (high-signal issues only). After PR creation, a CI status bar with Auto-fix and Auto-merge toggles. Permission mode selector beside send button: Manual (asks; shows a diff to accept/reject), Accept edits, Plan, Auto (background classifier), Bypass permissions; remembered per folder (Plan is per session). External-site permission cards: Allow once / Always allow / Deny. Computer-use prompts: "Allow for this session" / "Deny" with tiers view-only, click-only, full. Stop button or Esc interrupts; typing a correction + Enter is queued and read after the current action.
**Onboarding/auth/model**: install, launch, sign in, click Code tab (quickstart https://code.claude.com/docs/en/desktop-quickstart, not read). Before the first message the prompt area has four pickers: Environment, Project folder, Model (dropdown next to send, changeable mid-session), Permission mode. A usage ring beside the model picker shows context and plan usage. Enterprise: Bedrock, Google Agent Platform, Foundry, gateway. `/desktop` in the CLI hands a session to the app (subscription sign-in only, not API key). In-app API-key sign-in flow: NOT verified.
**Shortcuts** (Cmd/Ctrl+/ lists them): N new session, W close, Ctrl+Tab / Ctrl+Shift+Tab or Cmd+Shift+] / [ cycle sessions, Esc stop, Cmd+Shift+D diff, Cmd+Shift+B browser, Cmd+Shift+S select browser element, Ctrl+` terminal, Cmd+\ close pane, Cmd+; side chat, Ctrl+O view mode, Cmd+Shift+M permission menu, Cmd+Shift+I model menu, Cmd+Shift+E effort menu, 1-9 pick item in an open menu.
**Worth borrowing**: pre-send picker bar (env/folder/model/mode); keyboard openers for mode/model/effort; tool calls collapsed by default with three verbosity levels; diff-stat chip as entry to review; batched line comments; drag-to-arrange panes; modifier-click split; worktree toggle at session start; usage ring.
Secondary: https://pasqualepillitteri.it/en/news/866/claude-code-desktop-redesign-parallel-sessions

## 2. OpenAI Codex app - LOW verification depth
Official docs moved: developers.openai.com/codex/app redirects (308) to https://learn.chatgpt.com/docs/app. The fetched summary suggests the Codex app is now presented inside a "ChatGPT desktop app" ("command center for complex work", projects and chats, "every chat in view", choose ChatGPT or Codex at startup, Chat vs Work modes). https://learn.chatgpt.com/docs/features lists headings only: integrated terminal, code review with diff/inline comments, git worktrees, "Approvals & security" with sandbox modes, skills, model and reasoning selector, browser, computer use, scheduled tasks, plugins, voice, keyboard shortcuts, multiple layouts. No detail beneath them was obtained.
**Timeline**: macOS launch 2026-02-02; Windows via Microsoft Store 2026-05-29 with computer use on Windows apps and mobile remote control from ChatGPT iOS/Android (https://vibecoding.app/blog/openai-codex-app-review ; https://techinformed.com/openai-ships-codex-macos-app-as-ai-coding-shifts-toward-parallel-agents/).
**Layout** (third-party review, not official): "top-level tabs for different Codex surfaces, a project thread list on the left, and a central panel for the active agent" (vibecoding.app). Threads grouped by project (https://www.verdent.ai/guides/what-is-codex-app).
**Parallel work**: each agent gets its own git worktree; local vs cloud work distinguished; scheduled automations run in background and land in a review queue (vibecoding.app, techinformed).
**Diffs/approvals**: review pane shows files changed, commands run, test results; approve, ask for revisions, or push to a GitHub PR; comment directly on diffs; in-thread diffs; a cross-agent "review queue with inline diff" (verdent, techinformed, vibecoding). Windows: PowerShell sandbox, "Ask for approval" in the composer, selectable editor and terminal (PowerShell/CMD/Git Bash/WSL), optional WSL2 agent; `winget install --id 9PLM9XGG6VKS -s msstore` (https://learn.chatgpt.com/docs/windows/windows-app).
**Auth/model**: ChatGPT account sign-in is referenced. ## 3. Hermes Desktop (Nous Research) - sources: https://github.com/NousResearch/hermes-agent/blob/main/website/docs/user-guide/desktop.md ; https://github.com/NousResearch/hermes-agent/tree/main/apps/desktop ; https://www.digitalapplied.com/blog/hermes-agent-desktop-app-complete-guide-2026
**Stack**: Electron shell, React with @assistant-ui/react transcript, headless `hermes serve` backend over JSON-RPC/WebSocket, shared bridge with the browser dashboard. Sessions are shared with CLI/TUI/web.
**Layout**: chat-first; left sidebar (sessions/profiles); right pane with file browser + terminal; preview rail rendering web pages/files/tool outputs beside chat; bottom status bar. Interface mode Advanced vs Simple (collapsed technical details). Layout templates Basic, Focus, Terminal Deck, Quad. Multiple tabs and windows; HUD mode (floating chrome-free composer over other apps); global Quick Entry hotkey.
**Parallel/agents**: tabs, new windows, worktrees (Cmd/Ctrl+Shift+B), "Bot Mode" roster of agent profiles with group chat rooms, multi-agent Kanban, "Subagents frame" above the composer listing live workers with steer/stop, task progress above composer, `@session` linking across profiles. Unsent drafts and scroll position survive lost sessions.
**Tool calls/diffs/approvals**: streaming tool output with structured summaries; Git review pane (Cmd/Ctrl+G): branches, diffs, staging, commit-message generation, PR creation; per-session YOLO toggle in status bar bypasses dangerous-command prompts (the normal approval card design was not described in what I read); context meter (click for token breakdown), optional cache-hit rate and tokens/sec; error cards naming the failing layer (provider/endpoint/auth/gateway) with recovery actions.
**Onboarding/auth/model**: first-run overlay: local install (pick provider and model) or remote gateway (token/OAuth). Settings > Providers manages API keys and OAuth per provider (Nous Portal, OpenRouter, xAI SuperGrok OAuth, NVIDIA NIM, Hugging Face, OpenAI-compatible; 64K min context per digitalapplied). Sticky composer model picker that does not overwrite the default, reasoning-effort pill, per-model presets, starred favourites (shift-click), mid-chat switch resets prompt cache. Settings > Gateways: Local, Remote, Hermes Cloud, SSH, named registry.
**Shortcuts**: Cmd/Ctrl+K palette, N new session, Shift+N window, T tab, Ctrl+Tab cycle, Ctrl+1-9 jump, W close, Shift+T reopen, B sidebar, J right pane, Ctrl+` terminal, Ctrl+Shift+` new terminal, G git review, Shift+B worktree, Shift+H HUD, F find, comma settings, / shortcuts list (all rebindable), Shift+X light/dark.
**Visual**: light/dark/auto; VS Code Marketplace themes installable in-app; per-profile rail color; chat font choices incl. OpenDyslexic; Memory Graph of skills/memories; artifacts gallery; hot-reload desktop plugins.
**Borrow**: sticky model picker + reasoning pill; subagents frame with steer/stop; error cards naming the failing layer; context meter with breakdown; draft recovery; command palette + rebindable keys; Simple vs Advanced mode.
